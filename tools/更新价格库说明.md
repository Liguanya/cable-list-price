# 电缆价格库每月更新流程

## 数据源（官方免费）
天津市住建委 · 京津冀协同板块 · 价格信息：
https://zfcxjs.tj.gov.cn/ztzl_70/jjjgcjjjyth/jjjgx/jgxx/index.html

每月发布「京津冀建设工程人工、材料市场价格」RAR 包，解压后取
**「...主要材料市场价格-天津.pdf」**。
发布节奏：当月信息约在次月中旬发布（如 2026年9月期 → 2026-10-13 发布）。

## 数据口径（需与业主/审计确认后固定）
- PDF 表格列为：序号 / 材料名称 / 规格型号 / 单位 / **中准价格(含税)** / 区间最高最低 / 备注
- 网站组价需要**中准价·除税价**：当前按材料增值税率 13% 折算
  `除税价 = 含税价 ÷ 1.13`
- ⚠️ 待确认：天津造价信息期刊订阅版是否直接提供除税列；若有则优先采用官方除税价，不再折算
- 单位：电缆均为 元/m，与网站工程量单位一致
- 官方共享版仅含**铜芯**（YJV / YJV22）；**铝芯 YJLV 无数据**，暂走估算/留空

## 更新步骤
1. 下载当月 RAR，用 unrar 解压，定位天津材料 PDF
2. `pdftotext -layout 文件名.pdf out.txt`
3. 运行提取脚本（见 tools/，按"电线电缆"章节行解析，取中准价列）
4. 映射成网站结构：material/model/cores/section/spec/unit/price_incl/price/source
5. 除税折算（round 2 位），生成一期 period 对象
6. **unshift 到 data/prices.js 的 CABLE_PRICE_PERIODS 数组最前**
7. 网站期号下拉自动出现新期，历史期保留不动（结算可追溯同期价）

## 价格匹配分层（app.js lookupPrice，已实现）
官方精确匹配 > 同型号同芯结构相邻截面线性插值 > 同芯结构就近截面 >
同型号同芯结构跨铠装兜底 > 同材质同芯结构兜底（强制"请人工复核"）
- 单芯/多芯绝不跨结构插值
- 插值/估算在单元格标注依据，official 精确价不标注
- 完全无数据返回 null，显示"待录入"，绝不硬凑错误价
