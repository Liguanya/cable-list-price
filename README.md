# 电力电缆清单定额智能组价系统

天津2025清单计价规范 · Excel上传自动识别铜芯/铝芯与截面 · 自动套定额 · 主材价联动天津信息价

## 使用
打开 `index.html`（或访问 GitHub Pages 地址），上传工程量清单 Excel：
- A列：序号
- B列：项目名称（电缆名称及截面，如 `铜芯电力电缆 YJV-4x35+1x16`，纯型号写法亦可）
- C列：工程量（m）

选择「广联达 / 建经科技」格式后一键导出，全部计算在本地浏览器完成，不上传任何数据。

## 规则
- 清单统一套用 `030409001 电力电缆`
- 定额分档（按主芯截面）：
  - 铝芯：2-566(≤10) / 2-567(≤35) / 2-568(≤120) / 2-569(≤240) / 2-570(>240，含>400)
  - 铜芯：2-576(≤10) / 2-577(≤35) / 2-578(≤120) / 2-579(≤240) / 2-580(>240，含>400)
- 主材价：天津市工程造价信息 **中准价·除税价（元/m）**；缺规格按同型号同芯结构相邻截面插值/就近估算并标注
- 控制电缆（KVV等）不属于电力电缆定额，系统保留行并提示人工处理

## 每月价格更新
在 `data/prices.js` 的 `CABLE_PRICE_PERIODS` 数组最前面追加一期即可，网站期号下拉自动识别。
